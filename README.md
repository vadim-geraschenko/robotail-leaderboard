# Таблица лидеров

Данные лежат в `src/data/leaderboards.json`. Там список автоматов и результаты игроков в формате:

```ts
{
  id: string;
  playerName: string;
  wins: number;
  score: number;
}
```

Основная логика в `src/services/leaderboardService.ts`. Ранжирование идёт в первую очередь по количеству побед, при равном числе побед — по очкам. Данные разбиваются на страницы по максимум 10 строк, а также собирается общая таблица лидеров, где игрок идентифицируется по имени.

Компоненты лежат в `src/components`:

- `LeaderboardScreen` собирает один экран таблицы.
- `LeaderboardHeader` показывает название, картинку автомата и текущие места.
- `LeaderboardTable` показывает строки таблицы и по-разному обрабатывает локальный и общий рейтинг.

`src/App.tsx` отвечает за автоматическое переключение страниц. Интервал задается через `PAGE_DURATION_MS`. По умолчанию 5 сек.

Основные типы содержатся в `src/types/leaderboard.ts`:

- `MachineResult` — результат игрока на одном автомате;
- `Machine` — автомат со списком результатов;
- `GlobalLeaderboardEntry` — объединенный результат игрока по всем автоматам;
- `LeaderboardPage` — одна страница таблицы с диапазоном мест и строками.

Стили разделены рядом с компонентами: `App.css` задает общий фон и враппер, а CSS-файлы компонентов отвечают за шапку, таблицу, подсветку топ-3 и анимации переходов.
